# 部署交付

本目录面向实施人员和交付人员，按“理解目录、构建镜像、在线部署、离线迁移”的递进顺序组织。

## 在线环境

1. [目录语义](concepts.md)：区分源码目录、部署模板目录和最终运行目录。
2. [镜像构建说明](build.md)：说明哪些场景会构建镜像、如何跳过构建、镜像名从哪里来。
3. [在线部署](deploy.md)：在目标机器生成独立运行目录并启动服务。
4. [配置说明](configuration.md)：修改端口、模型、挂载目录、HTTP API 参数和热词文件。

## 离线环境

1. [离线打包](offline-package.md)：在有网环境制作包含镜像、运行数据和项目参考资料的离线包。
2. [离线部署](offline-deploy.md)：在无网环境导入镜像、还原运行数据并启动服务。
