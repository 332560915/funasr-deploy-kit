# Usage Scenarios

This directory is for first-time users and API callers. Read it in the order of running the stack first, then calling the API.

## Recommended Order

1. [Getting Started](getting-started.md): clone the project, build images, start default services, and verify the stack.
2. [HTTP API](api.md): learn the transcription endpoint, upload limit, Swagger UI, and response format.

If the target environment has no network access, skip quick start and go to [Offline Deployment](../deployment/offline-deploy.md).
